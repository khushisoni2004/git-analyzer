## 🚀 About GitScope

**GitScope** is a modern and responsive **GitHub Profile Explorer** powered by the **GitHub REST API**.

Simply enter any public GitHub username and instantly explore their profile, repositories, followers, stars, programming languages, forks, issues and developer information.

```text
🔍 Search Username
        ↓
🐙 GitHub REST API
        ↓
👤 Fetch Developer Profile
        ↓
📦 Fetch Public Repositories
        ↓
⭐ Calculate Stars & Languages
        ↓
🚀 Display Developer Dashboard
