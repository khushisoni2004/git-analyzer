## 🚀 About GitScope

**GitScope** is a modern GitHub Profile Explorer built with **HTML, CSS & JavaScript** and powered by the **GitHub REST API**.

Search any public GitHub username and instantly explore their **profile, repositories, followers, stars, languages, forks & issues**.

```text
🔍 Search Username
       ↓
🐙 GitHub REST API
       ↓
👤 Fetch Profile + 📦 Repositories
       ↓
⭐ Stars + 💻 Languages + 👥 Followers
       ↓
🚀 Developer Dashboard
```

---

## ✨ Features

| ⚡ Feature | 🚀 What it does |
|---|---|
| 🔍 **Profile Search** | Search any GitHub developer |
| 👤 **Developer Info** | Avatar, bio, location & company |
| 📦 **Repositories** | Shows top public repositories |
| ⭐ **Total Stars** | Calculates repository stars |
| 💻 **Top Language** | Detects most-used language |
| 👥 **Followers** | Followers & following stats |
| 🍴 **Repo Stats** | Forks, stars & open issues |
| ⏳ **Loader** | Animated API loading |
| 🚨 **Error Handling** | Handles invalid usernames |
| 📱 **Responsive** | Mobile, tablet & desktop ready |

## 🔗 API

```javascript
// Developer Profile
https://api.github.com/users/{username}

// Public Repositories
https://api.github.com/users/{username}/repos?per_page=100&sort=updated
```
